# 感知&执行层：
1. 麦克风INMP441，负责采集音频数据
2. RFID读卡器，负责读取卡片UID
3. 功放MAX98357A，负责放大音频数据
4. 扬声器，负责播放音频数据

# 设备主控层：
1. 音频任务处理：
    1. 将采集到的PCM音频用于离线语音识别，在识别到唤醒词后将采集到的音频编码为Opus格式并自定义音频帧格式
    2. 将自定义音频帧格式的数据通过WebSocket流式发送到服务器端
    3. 接收服务器返回的音频数据，将其从Opus格式解码为PCM格式并通过功放以及扬声器播放

2. 建立阿里云物联网平台链接：
    1. 通过阿里云物联网平台实现手机APP与ESP终端设备之间的数据流通
    2. 通过手机端设置相应RFID卡片UID代表的任务
    3. 通过阿里云物联网平台获取任务完成情况，展示在手机APP上

3. RFID任务处理：
    1. 读取RFID卡片UID，识别对应任务，建立习惯养成机制

4. 建立websocket客户端：
    1. 与服务器进行链接与数据传输

5. 实时时钟任务
    1. 获取UNIX时间戳并同步到ESP设备时钟，不断校准时钟

# 平台层：
1. 阿里云物联网平台：
    1. 建立手机APP与ESP终端设备之间的数据云流转

# 服务层：
1. 建立ESP终端设备与AI大模型API接口之间的链接
2. 向AI大模型投喂流式音频数据，接收AI大模型返回的流式音频数据并转发给ESP终端设备
3. 向AI大模型投喂照片与人物画像，接收AI大模型返回的AI绘图图片数据并转发给ESP终端设备
4. 实现高并发，允许大量设备接入服务器并与AI大模型进行通信

# 智能服务层：
1. 豆包实时语音API，通过输入流式音频数据获取回答的流式音频数据
2. 豆包绘图API，通过输入照片与人物画像获取AI大模型返回的AI绘图图片数据

# 手机端APP：
1. 展示儿童成长轨迹
2. 反馈儿童健康习惯养成任务完成状态
3. 配置健康习惯养成任务
4. RFID卡片UID任务绑定
